Live Outlook Feed

This link is a live calendar feed of every event and deadline on this planner. Subscribe once in Outlook and it stays up to date automatically — every save here appears in Outlook within a few hours, usually minutes. No re-downloading files.

To add it to the staff Events Calendar: sign in to Outlook as the account that owns the Events Calendar, then go to Calendar → Add calendar → Subscribe from web, paste the link, give it a name like “USA Diving Season Calendar,” and save. Anyone the Events Calendar is shared with will then see everything automatically. The same steps work for any personal Outlook or Google calendar.
